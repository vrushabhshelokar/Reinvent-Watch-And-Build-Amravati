## Project decisions

- **Event name:** Reinvent Watch And Build — Amravati
- **Audience:** College students
- **Primary goal:** Completed registrations through Luma
- **Entry fee:** ₹0, subject to final organizer confirmation before publication
- **Stack:** Next.js App Router, TypeScript, Tailwind CSS
- **Hosting target:** Vercel
- **Registration:** External Luma page; no duplicate on-site registration form
- **Analytics:** Privacy-conscious analytics plus registration CTA click measurement
- **Visitor count:** Display only a real, clearly defined metric; never invent or seed a public count
- **Backend/database:** Not required for the initial landing page
- **Branding:** Do not imply official AWS re:Invent sponsorship, endorsement, or affiliation unless explicitly authorized
