## Global content rules

- Write for college students, including newcomers to cloud computing.
- Prefer concrete details over generic claims.
- Do not invent attendance figures, speakers, partners, event activities, giveaways, certificates, credits, or scarcity.
- Use the approved event name consistently: **Reinvent Watch And Build — Amravati**.
- Use “AWS-inspired” only as contextual description where accurate. Do not state or imply official AWS sponsorship or affiliation without authorization.
- The registration destination is Luma: `[CONFIRM: LUMA_REGISTRATION_URL]`.
- Entry fee is planned as ₹0; reconfirm before launch.
- All dates/times should use India Standard Time (IST) and be unambiguous.
